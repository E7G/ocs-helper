# OCS Helper

一个用于超星学习平台的自动化学习辅助脚本，旨在提高在线学习体验。ocs辅助脚本，用于功能增强，防止视频卡住及使用页面上的下一节按钮来跳转下一节

## 功能特性

- 🎥 **视频卡顿检测与自动处理**：自动检测视频播放是否卡顿，并在检测到卡顿时自动跳转到视频结尾
- 📚 **自动课程导航**：当任务点完成后，自动点击"下一节"按钮继续学习
- 🖼️ **多级iframe支持**：支持在嵌套的iframe结构中查找视频元素和按钮
- 🎯 **智能任务点检测**：准确识别任务点完成状态
- 🎛️ **可视化控制面板**：提供简洁的控制面板，可随时暂停/恢复脚本运行
- 📊 **详细日志输出**：提供详细的调试信息，便于问题排查
- 🚦 **最后一节检测**：智能识别最后一节课程，避免无效查找

## 安装方法

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 [auto-study-helper.user.js](auto-study-helper.user.js) 下载脚本
3. 在Tampermonkey中安装脚本
4. 访问超星学习平台课程页面，脚本将自动运行

## 使用说明

### 基本使用

1. 安装脚本后，访问超星学习平台的课程页面
2. 脚本会自动在页面右上角显示控制面板
3. 控制面板显示当前运行状态，可以点击"暂停/开始"按钮控制脚本运行

### 控制面板功能

- **状态显示**：显示脚本当前运行状态（运行中/已暂停/已暂停(最后一节)）
- **暂停/开始按钮**：控制脚本的运行和暂停

### 工作原理

1. **视频检测**：脚本会定期检测页面中的视频元素，支持在多级iframe中查找
2. **卡顿检测**：当视频播放但时间不变化超过设定阈值（默认5秒）时，判定为卡顿
3. **自动跳转**：检测到卡顿时，自动将视频进度跳转到接近结尾的位置
4. **任务点检测**：检测任务点是否已完成，通过aria-label和class属性判断
5. **自动导航**：当任务点完成后，查找并点击"下一节"按钮
6. **最后一节识别**：连续多次找不到下一节按钮时，判定为最后一节并停止查找

## 配置选项

脚本内部提供以下配置选项（可在脚本中修改）：

```javascript
const CONFIG = {
    checkInterval: 2000,        // 检测间隔（毫秒）
    videoStuckTime: 5000,       // 视频卡住时间阈值
    debug: true,                // 调试模式
    maxConsecutiveNoButton: 3   // 连续找不到下一节按钮的最大次数
};
```

## 兼容性

- **浏览器**：Chrome、Firefox、Edge等支持Tampermonkey的浏览器
- **目标网站**：超星学习平台 (`https://mooc1.chaoxing.com/mycourse/studentstudy*`)
- **视频类型**：支持HTML5视频元素（`video#video_html5_api.vjs-tech`）

## 注意事项

1. **使用风险**：本脚本仅用于学习目的，请遵守平台使用规则
2. **调试信息**：默认开启调试模式，可在浏览器控制台查看详细日志
3. **跨域限制**：由于浏览器安全限制，无法访问跨域iframe内容
4. **平台更新**：如平台UI更新可能导致脚本失效，需要更新选择器
